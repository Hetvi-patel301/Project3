# Student Data Organizer

### Project Description

The **Student Data Organizer** is a Python-based console application used to manage student information.

This project allows the user to:

- Add student information
- Display all students
- Update student information
- Delete a student
- Display subjects offered
- Exit the program

The project demonstrates the use of Python **List, Dictionary, Tuple, Set, Loops, Conditional Statements, and Match-Case**.


### Technologies Used

- Python
- List
- Dictionary
- Tuple
- Set
- `while` loop
- `for` loop
- `if-elif-else`
- `match-case`



### Features

#### 1. Add Student

The user can add a new student by entering:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects

The student information is stored in a **dictionary** and then added to the `students` **list**.


#### 2. Display All Students

The user can display all the students stored in the program.

The program displays:

- Student ID
- Name
- Age
- Grade
- Subjects


#### 3. Update Student Information

The user can update information of an existing student using the **Student ID**.

The following information can be updated:

1. Name
2. Age
3. Grade
4. Subjects


#### 4. Delete Student

The user can delete a student by entering the **Student ID**.

The program searches for the student and removes the matching student from the `students` list using the `del` keyword.



#### 5. Display Subjects Offered

The program displays the subjects associated with each student.

Subjects are stored using a **set**, which helps avoid duplicate subjects.


#### 6. Exit

The user can select option 6 to exit the program.


### Data Structures Used

#### List

The `students` list stores all student records.


#### Dictionary

Each student's information is stored in a dictionary.


#### Tuple

Student ID and Date of Birth are stored together in a tuple.


#### Set

Subjects are stored as a set.




### CRUD Operations

The project performs basic **CRUD operations**:

| Operation | Feature |
|---|---|
| Create | Add Student |
| Read | Display All Students |
| Update | Update Student Information |
| Delete | Delete Student |
